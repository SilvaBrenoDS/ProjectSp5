# ProjectSp5# Análise de anúncios de veículos

Este projeto apresenta uma análise exploratória de dados de anúncios de veículos nos EUA.

O aplicativo web foi criado com Streamlit e permite:

- visualizar um histograma da quilometragem dos veículos;
- visualizar um gráfico de dispersão que relaciona quilometragem e preço.

Tecnologias utilizadas: Python, pandas, Plotly Express e Streamlit.
